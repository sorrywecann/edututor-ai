EduTutor.AI v5.0Abstrakt · §1 Prehľad systému
Abstrakt

EduTutor.AI je hlasovo ovládaná AI tutorská platforma pre slovenský jazyk, vyvinutá ako prototyp novej generácie vzdelávacieho softvéru. Systém kombinuje technológie spracovania reči (STT/TTS), veľké jazykové modely (LLM), retrieval-augmented generation (RAG), cross-session memóriu a realistickú animáciu 3D MetaHuman avatara s lipsync synchronizáciou. Platforma je navrhnutá ako modulárna a model-agnostická — každá vrstva je nezávisle konfigurovateľná a za behu prepínateľná bez reštartu. Verzia v5.0 (máj 2026) pridáva: cross-session memory (user_profile + episodic_memory), podcast generáciu z dokumentov, Ask Mode pre one-shot otázky, Text2Face presety pre 9 emócií, env-tunable konverzačný timing visem a WS reconnect s exponential backoff. Lipsync systém má dnes tri produkčné cesty: text→viseme (14 SK vizémov, ±25 ms), Azure phoneme timing (±5 ms) a ARKit 52-kanálový režim (HuBERT @60fps). Dokument je primárnym technickým artefaktom pre Output 3 grantovej zmluvy 09I05-03-V04-00072.

2.3 SSE streaming formát — hlasová konverzácia

Backend streamuje odpoveď cez SSE. Pre každú akumulovanú vetu sa emituje komplexný event obsahujúci text, audio, emóciu a lipsync dáta. Pre v5.0 pribudli ARKit frames + audioPositionMs/sentenceIdx polia pre presný UE5 lookup.

{"type": "context",  "chunks": [...]}                   ← RAG metadáta
{"type": "text",     "delta": "..."}                    ← progresívne tokeny
{"type": "sentence_start", "text": "...", "viseme_timeline": [...]}
{"type": "audio_chunk", "audio": "base64(mp3)"}         ← TTS chunky
{"type": "sentence_end",
  "audio": "base64(mp3 full)",
  "emotion": "proud",    "intensity": 0.75,
  "viseme_timeline": [{t, viseme, weight, start_ms, duration_ms}],
  "arkit_frames":    [{start_ms, duration_ms, arkit:{...}}],  ← 52 ch
  "duration_ms": 2200,
  "audioPositionMs": 0,  "sentenceIdx": 0
}
{"type": "done", "full_text": "..."}

4.2–4.5 Štyri lipsync režimy

1

Text estimation (±25 ms)

LLM text → grafémy → SK fonetické pravidlá → viseme timeline. Aktívny pre všetky TTS providery. Nulové závislosti, offline-ready.

2

Azure phoneme timing (±5 ms)

Azure TTS vráti JSON s phoneme-level timestamp. Mapovanie Azure phoneme ID → SK vizém. Najvyššia presnosť — vyžaduje Azure kľúč.

3

ARKit 52-kanálový (audio2lipsync)

HuBERT + Transformer @60fps. Model: fotonlabs/unreal-audio2lipsync (MIT, 315 MB). Frame-perfect blendshape výstup pre celú MetaHuman tvár.

4

Hybrid (auto-fallback)

Ak audio2lipsync nie je dostupný → plynulý fallback na text mode. Frontend deteguje arkit_frames v SSE evente a volá správny UE5 bridge. Default v produkcii.

13.2 Docker — rýchly štart (odporúčané)

Požiadavky: Docker Desktop 4.0+ · 8 GB RAM · 20 GB disk · internet (prvý štart)

git clone https://github.com/princeofwellness/edotutor.git
cd edotutor
cp .env.example .env                  # pridať aspoň jeden LLM API kľúč
docker compose up --build             # prvý štart 3–5 min (model downloads)

# Produkcia s Nginx + Prometheus + Grafana:
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d

UI: http://localhost:3000 · API docs: http://localhost:8000/docs
Login: edututor / edututor2026 (dev mode)

13.3 Manuálne (bez Docker)

./start.sh         # Mac/Linux — auto-installs Python 3.11+, Node, pnpm
start.bat          # Windows
# Backend na :8000, frontend na :3000, prvý štart 2-3 min
