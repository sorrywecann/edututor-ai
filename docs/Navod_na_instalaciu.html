EduTutor.AI

Slovenský AI tutor s lokálnym jazykovým modelom a živým 3D avatarom. Verzia 0.8.8.

Inštalácia

  1. Spusti EduTutor-Setup-0.8.8.exe
  2. Preklikaj sa sprievodcom inštalácie
  3. Otvor EduTutor z desktopovej ikony

Pri prvom spustení sa automaticky stiahne MetaHuman avatar (~1.7 GB). Ďalšie spustenia sú už okamžité.

Systémové požiadavky

  • Windows 11 (64-bit)
  • 16 GB RAM odporúčané
  • ~6 GB voľného miesta (+1.7 GB pre avatar)
  • NVIDIA GPU s aktuálnym ovládačom
  • Pripojenie na internet pri prvom spustení

Overenie pravosti (voliteľné)

V cmd alebo PowerShelli:

certutil -hashfile EduTutor-Setup-0.8.8.exe SHA256

Porovnaj výsledok s obsahom EduTutor-Setup-0.8.8.exe.sha256. Musia byť identické.

Kde sú tvoje dáta

  • Konfigurácia a API kľúče: %APPDATA%\edututor-desktop\
  • LLM modely a UE5 avatar: %APPDATA%\edututor-desktop\ollama-models\ a \ue5\
  • Konverzácie: lokálne v SQLite databáze, nikam sa neposielajú
  • API kľúče sa odosielajú výhradne providerovi (OpenAI, Anthropic, ...), nikam inam

Odinštalovanie

  • Štart Menu → EduTutor.AI → Uninstall EduTutor.AI, alebo
  • Windows → Nastavenia → Aplikácie → EduTutor.AI → Odinštalovať

Užívateľské dáta v %APPDATA%\edututor-desktop\ ostanú zachované. Odstráň ručne ak chceš úplne čistú stopu.
