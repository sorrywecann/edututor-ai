Výsledok porovnaj s obsahom súboru EduTutor-Setup-0.8.7.exe.sha256. Hodnoty musia byť identické.

04Inštalácia

  1. Spusti EduTutor-Setup-0.8.7.exe dvojklikom — nie je potrebné spustenie ako Administrátor.
  2. Potvrď cieľový priečinok (predvolene %LOCALAPPDATA%\Programs\EduTutor.AI).
  3. Inštalátor automaticky vytvorí desktopovú ikonu aj odkaz v Štart Menu.
  4. Po dokončení sa aplikácia dá spustiť bez reštartu.

05Prvé spustenie

  1. Privíta ťa Vitaj obrazovka s pulzujúcim Orb avatarom. Stlač Vstúpiť →.
  2. Zadaj svoje meno a vyber štýl tutora (Vážny / Praktický / Pohodový).
  3. V Hardvérových nastaveniach si môžeš:
    • Vybrať LLM model — lokálne Ollama (Gemma, Llama, Qwen, Mistral) alebo cloud (OpenAI, Anthropic, Groq, DeepSeek)
    • Vybrať hlas tutora — Lukáš alebo Viktória
    • Pridať vlastný API kľúč (po overení sa rovno aktivuje pre chat)
    • Nainštalovať lokálny Piper TTS so slovenským hlasom (offline syntéza)
    • Upraviť systémový prompt v záložke Mozog
Tip Esc kdekoľvek v nastaveniach ťa vráti späť na predošlú obrazovku.

06Bezpečnosť

  • Aplikácia beží v Electron sandbox móde s aktívnym webSecurity.
  • API kľúče sa ukladajú lokálne do %APPDATA%\edututor-desktop\.env.
  • Kľúče sa nikdy neposielajú nikam okrem priamo na zvoleného providera (OpenAI, Anthropic, ...).
  • Dev-only endpointy sú za EDU_DEV_MODE=1 environment gateom — bežný používateľ ich nevidí.

07Odinštalovanie

Dve cesty, obe rovnocenné:

  • Štart Menu → EduTutor.AI → Uninstall EduTutor.AI
  • Windows Nastavenia → Aplikácie → EduTutor.AI → Odinštalovať

Užívateľské dáta v %APPDATA%\edututor-desktop\ zostanú zachované — odstráň ručne ak chceš úplne čistú stopu.
