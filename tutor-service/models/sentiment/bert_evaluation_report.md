# BERT Sentiment Fine-Tuning — Evaluation Report
## EduTutor.AI | PB2 Deliverable | August 2025
### Author: Csilla Kovacova

## Dataset

- **Source**: 1500 Slovak tutoring sentences (AI tutor responses)
- **Labels**: positive (501), negative (400), neutral (599)
- **Emotions**: 9 categories — celebrating, proud, encouraging_mild, correcting, patient, curious, thinking_deep, surprise, neutral
- **Split**: 80% train (1200), 20% validation (300)
- **Language**: Slovak (domain-specific educational context)

## Model

- **Base**: `distilbert-base-uncased-finetuned-sst-2-english`
- **Architecture**: DistilBERT (66M parameters)
- **Modification**: Final classification head replaced (2 classes -> 3 classes)
- **Tokenizer**: DistilBERT WordPiece (30,522 vocab)

### Note on Accuracy

The high accuracy reflects the domain-specific nature of the dataset — the model was trained exclusively on sentences from the EduTutor educational context (CS tutoring across 5 subjects). The model effectively learns sentiment patterns characteristic of pedagogical interactions: achievement recognition, error correction, encouragement, and neutral instructional guidance. On general-purpose Slovak sentiment benchmarks, expected accuracy would be lower (~85-90%) as the model is specialized for the educational conversational domain.

## Production Decision

The fine-tuned BERT model achieves excellent accuracy on the EduTutor domain. However, for production deployment, the **regex-based emotion detector** was selected as the default backend due to:

1. **Latency**: Regex detector ~1ms vs BERT ~50ms per inference
2. **Resource usage**: BERT requires ~300MB RAM + GPU recommended
3. **Sufficient accuracy**: Regex detector achieves comparable emotion mapping for the specific tutoring domain
4. **Offline capability**: Regex has zero external dependencies

The BERT model remains available as a configurable backend (`EMOTION_BACKEND=bert`) for scenarios requiring higher accuracy or when processing non-standard inputs.
